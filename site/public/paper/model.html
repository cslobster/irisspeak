Model

IrisSpeak-135M

IrisSpeak-135M is based on SmolLM2-135M-Instruct. We add a card layer to the transformer: a 3,096-row matrix with one row per vocabulary card, a name slot, and an end-of-message marker. The rows serve two purposes: as input embeddings for the cards already tapped, and as the output head that turns the final hidden state into one logit per card. The whole model was then fine-tuned on next-card states derived from AAC conversation data, so it learns how people who use AAC reply to a communication partner rather than how to write text.

Architecture

Setting: school.
Partner: What did you do today at school?
Reply cards:            ← text, through the normal token embedding (49,152 rows kept)
<start> <card_0102>    ← cards, through the 3,096 trainable card rows
      │
   30 transformer layers, hidden 576 (SmolLM2-135M, Apache 2.0)
      │
   last hidden state · card rows ᵀ  → 3,096 logits → softmax → probability per card
  • Each card row is initialised from the mean of SmolLM2's own embeddings of the card's spoken form, so "koala" starts near "kangaroo" before any training example, and rows for rare cards inherit meaning from the base model.
  • Only the 3,096 card rows are scored. The original 49,152-token language-model head is not used at inference, so the model never produces free text.
  • Inference per tap is one forward pass over the prompt plus tapped cards. In the product the partner turn is prefilled once and each tap appends one token to a KV cache; the demo recomputes the full sequence for simplicity.

Loading it yourself

# Python, PyTorch
from train_smollm import CardModel, encode_batch, load_vocab, MODEL   # scripts.zip on the data page
base = AutoModelForCausalLM.from_pretrained(MODEL)
model = CardModel(base, 3096, torch.zeros(3097, 576)); model.load_state_dict(torch.load("card_model.pt"))
logits, hidden = model(*encode_batch(tok, [state], id2idx, start_idx=3096, device="cpu"))

# Browser, onnxruntime-web (see demo.html)
session = await ort.InferenceSession.create(bytes, { executionProviders: ['wasm'] })
out = await session.run({ text_ids, text_mask, card_idx, card_mask })   // out.logits: Float32Array(3096)

Reranker

A three-layer feed-forward network over the model's top 100 candidates, about 6,000 weights, trained with a listwise loss on graded labels. Features: model log-probability and rank, bigram frequency, MiniLM similarity between the partner turn and the card, category and intent flags, core, safety, composable, multiword, prefix length, partner present. It adds 8 to 11 points of Recall@16 over the model alone. Its weights are global; personalisation enters as per-child count features, which are not part of this demo.
