How the systems compare

All systems are scored on the same held-out states with the same metric: is an acceptable next card in the top k? Two test sets: the general held-out set from the three corpora, and the question-answer subset where the partner asked a question and an AAC user replied in at most 5 cards.

v1 Gemini-2.5-Flash prototype versus v2 IrisSpeak-135M

The Gemini 2.5 Flash prototype asks a cloud model, once per parent message, for 12 topic nouns and 12 action verbs chosen from the full vocabulary pasted into the prompt, and shows the first four of each with fixed core and feeling cards. For this measurement its prompt was run with gpt-5.6-luna on the same vocabulary and the same question-answer states as IrisSpeak-135M plus the reranker. Six utterances, two steps each, so a sketch rather than a measurement.

Reading the examples: the LLM's picks are on the question's theme ("slice, two, one, pizza" for "one slice or two?") but often not the reply ("choice, decision, answer" for "did you pick the best option?", where the reply was "not sure"). The fine-tuned model has learned how people reply; the theme-locked prompt learns what the question is about.

Zero-shot use of the same small model

Before fine-tuning, SmolLM2-135M was tried as a scorer and as a generator. As a scorer with an instruction prompt it ranked the same generic phrases for every question and the true card sat in the thousands. As a few-shot dialogue generator it produced plausible AAC-style replies about half the time on question-answer states, but greedy decoding copied the examples and the outputs had to be mapped to cards. Neither approach beat counting; the pretrained model's value is realised by fine-tuning with card rows.

What each number means

  • Recall@1: the top prediction is acceptable. What the user sees first.
  • Recall@16: an acceptable card is on a 16-cell grid. The number that decides whether the user taps or searches.
  • Recall@100: the reranker's pool contains an acceptable card; the ceiling for anything downstream.
  • NDCG@16: ranking quality with graded labels (reference card 3, other acceptable 2).
Not yet measured: taps per utterance with a simulated user, cards moved per step, the cloud planner's contribution, and any human session. Those are in the experiment plan.
