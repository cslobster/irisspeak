How the IrisSpeak model was built

Six steps, in everyday words.

1. Start from an open model

We took SmolLM2-135M-Instruct from Hugging Face. It is a small, free language model that already understands English. It is about a thousand times smaller than ChatGPT, which is why it can run on a phone with no internet.

2. Change the model to work with cards

A language model normally guesses the next word. AAC users tap cards. So we added an extra layer to the model: a card layer with one row for each of the 3,094 cards. It does two jobs. It reads the cards already tapped into the model, and at the end it scores every card, so the model's output is one score per card instead of one score per word. The best-scoring cards go on the screen. Everything else in SmolLM2 stays as it was, and the whole model is then trained together.

3. Train it with AAC data

We used AAC conversation data from Hugging Face, plus the AAC datasets we collected (AACText and the Turk AAC dialogues). Each reply was turned into cards, for example "I want some juice" becomes I want → some → juice. Every step is one lesson: given the question and the cards so far, this is the next card. About 70,000 lessons in total.

Training is simple: show a lesson, let the model guess, tell it how wrong it was, adjust it a little. Repeat about 4,000 times.

Machineone Apple MacBook Pro laptop (M2 Max chip), no GPU servers
Training timeabout 2 hours (125 minutes)
Lessons69,676 examples, shown twice
Model size135 million parameters

4. Test it

We kept thousands of lessons the model never saw and asked: when it shows 16 cards, is the right one there? For question-and-answer turns, yes 7 times out of 10. The first suggestion is right about 4 times out of 10. A plain "most common cards" rule did clearly worse, and so did our earlier version that asked a big cloud model for the cards.

5. Add a small model that learns the person

A tiny second model reorders the cards using the child's profile and the cards they have used before. The more you use it, the better it fits you. Everything stays on the device.

6. Put it on the phone

The finished model is about 274 MB. The phone downloads it once and keeps it. After that every tap is answered on the phone in under a second.
